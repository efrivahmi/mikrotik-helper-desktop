# Perbaikan MikroTik Helper Desktop 1.1.1

Tanggal: 11 Oktober 2026.

## Penyebab yang ditemukan

- Shortcut membuka paket 1.0.0 dari 5 Oktober, sedangkan source 1.1.0 belum dipaketkan.
- Pekerjaan Agent/Skill tersimpan dengan error host key belum dipercaya. Aksi pada paket lama melewati alur persetujuan host key.
- Pemeriksaan TCP ke Invada 192.168.140.1:22 mengalami timeout. Pemilik mengonfirmasi sedang di luar lokasi dan tidak memiliki sambungan ke jaringan router.
- Snapshot impor lama masih berada di database paket lama. Data tersebut tidak membuktikan kondisi router saat ini.

## Perbaikan

| Bagian      | Perubahan                                                                                                                                                                                               |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Paket       | Versi 1.1.1; footer membaca app.getVersion(); installer shortcut menolak paket yang tidak sesuai source.                                                                                                |
| SSH         | Hubungkan memeriksa credential, alamat, TCP, fingerprint, autentikasi dan identity. Aksi Agent/Skill/Backup melanjutkan setelah host key diverifikasi.                                                  |
| Credential  | Validasi private key OpenSSH/PEM, penolakan public key, passphrase, dan laporan keyring terkunci. Credential lama tidak diteruskan ke target/metode berbeda.                                            |
| Pekerjaan   | Hasil diagnostik dan skill langsung dibuka; notifikasi akhir menampilkan selesai atau penyebab kegagalan. Sambungan terputus menghentikan pembacaan hasil.                                              |
| Monitoring  | Hanya snapshot dari SSH; snapshot lama ditandai historis. Data impor dikeluarkan dari dashboard. Nilai nol dibedakan dari data yang tidak terbaca.                                                      |
| Agent lokal | Workflow terpisah untuk kondisi, bandwidth/PCQ, jaringan/AP/switch, HotSpot, log, backup, dan print dari katalog. Permintaan di luar workflow mendapat panduan.                                         |
| Pengaturan  | Form API key dikosongkan hanya setelah save berhasil; cancel dialog tidak diberi notifikasi sukses.                                                                                                     |
| Perubahan   | Generator membaca profil RouterOS dengan/ tanpa tanda kutip; precondition/verify memerlukan tepat satu baris dengan nilai yang sesuai. Form tidak membawa batas atau verifier contoh yang sudah terisi. |
| Laporan     | Export menyertakan hasil diagnostik dan laporan tahap koneksi.                                                                                                                                          |

Pembuatan rencana tetap memerlukan evidence. Apply/rollback tetap melalui backup, review, grant nama router/hash, dan verifikasi. Perbaikan aplikasi ini tidak menjalankan perubahan konfigurasi router.

## Paket dan penggunaan

- Linux: `release/MikroTik-Helper-1.1.1-x86_64.AppImage` dan shortcut MikroTik Helper.
- Windows: `release/MikroTik-Helper-Setup-1.1.1-x64.exe` atau `release/MikroTik-Helper-Portable-1.1.1-x64.exe`.
- Buka Router → Periksa untuk melihat tahap yang gagal. Di luar jaringan management, sambungkan LAN/VPN sebelum Hubungkan.
- Untuk dialog bebas, isi endpoint/model yang benar-benar tersedia di Pengaturan. Workflow lokal tidak membutuhkan layanan model.

## Bukti dan batas pemeriksaan

TypeScript dan build renderer/main/preload berhasil. Paket Linux dan Windows dibangun dari source 1.1.1. Metadata paket, checksum artifact, dan kecocokan source terkemas dicatat dalam laporan lokal; build Windows dilakukan dari Linux.

Aplikasi Linux dibuka pada desktop pengguna. Database tidak lagi menyimpan snapshot impor sebagai data monitoring; inventory Invada dan skill tetap ada. Pengujian otomatis tidak dijalankan pada sesi ini. Instalasi/runtime Windows native, endpoint model nyata, autentikasi SSH Invada, skill/backup/router monitoring, serta apply/rollback pada RouterOS produksi belum diverifikasi.

Backup sebelum perubahan ada di `Documents/mikrotik-desktop-repair/20261011T062445Z/`: SQLite konsisten dan arsip source beserta app.asar lama. Pembacaan ulang arsip cocok SHA256; database backup lolos pemeriksaan integritas. Folder helper Python tidak diubah.
